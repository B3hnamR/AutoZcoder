# AutoZCoder 2.1.1

A patch release for the generator's "After signup" switch. Everything from 2.1.0
is included; this release fixes one claim path that ignored the switch.

## Generator

- Turning "After signup" off now also stops the legacy 100M invite claim. A saved
  `claim` choice (or a `claim: true` configuration seed) kept the invite pass
  armed, so a signup could still open a second browser window and run the invite
  flow while the switch read Off.
- The switch now reflects any armed claim pipeline, so a seeded or previously
  saved legacy claim shows as On instead of appearing off.
- Claiming only ever runs when the switch allows it. The manual "Claim 100M"
  action and the referral finisher are unchanged.

## Upgrading

Restart the gateway. No configuration or account data changes are required.
