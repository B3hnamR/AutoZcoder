# AutoZCoder 2.1.3

A maintenance release that finalizes the Windows desktop startup reliability fixes introduced in 2.1.2 and aligns the release validation suite.

## Desktop startup

- Keep gateway readiness checks on a direct connection to the local listener, bypassing inherited system HTTP proxy settings.
- Preserve scoped TLS certificate and hostname verification for configured HTTPS gateway origins.
- Improve startup diagnostics with readiness probe details and full background-worker exception tracebacks.

## Test and release reliability

- Update TLS audit tests to mock the desktop launcher's direct gateway URL opener, matching the current implementation.
- Validate the application version, Windows executable metadata, and release notes against the selected version tag.

## Upgrade

Replace the previous executable with the 2.1.3 build. Existing configuration and account data are preserved.
