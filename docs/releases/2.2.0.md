# AutoZCoder 2.2.0

Two exit networks are now built into the generator's IP source: Psiphon and
Surfshark. Both work like the existing sources (proxy pool, pinned proxy,
direct): each signup leaves through a different exit address.

## IP source

- Generator → IP source offers **Psiphon** and **Surfshark** next to the proxy
  pool. Choose regions (Psiphon) or locations (Surfshark), press Connect, and
  every signup takes the next ready exit; "Stay on one" pins a single one
  instead.
- Every region or location has its own connection and exit address, shown
  live in the panel with its state. **New address** reconnects one of them for a
  different exit without touching the others.
- Both can connect when the gateway starts. Start is refused with the reason
  when the selected network has no ready exit, instead of signing up from the
  local address by accident.
- Only the gateway's own requests use a tunnel: no adapter, route or DNS change
  on this computer, and the chosen network also works over an existing VPN.

## Psiphon

- Uses Psiphon's official `psiphon-tunnel-core` client, bundled for Windows and
  Linux x86-64 (GPL-3.0). Update servers runs one connection without a region to
  refresh Psiphon's server list; the bundled list is used until then.

## Surfshark

- Uses your own Surfshark subscription through its WireGuard manual setup: paste
  the key pair once (the public key is checked against the private one before it
  is saved). Locations come from Surfshark's public server list.
- Each location runs the bundled `wireproxy` client (ISC), Windows x64 and Linux
  x64/arm64. "New address" moves that location to another server in the same
  city when one exists, so the address really changes.
- The private key is stored in `vpn.json` (owner-only) and never sent back to
  the browser. A location's settings file is deleted as soon as its tunnel is up.

## Notes

- `cryptography` is now a Windows runtime dependency (the public key is derived
  with it); it was already required on Linux.
- Psiphon has no official Linux arm64 client, so it is not offered there.
  Surfshark works on arm64.
- Psiphon's licence (GPL-3.0) and wireproxy's (ISC) ship next to the binaries in
  `vendor/`.

## Upgrading

Restart the gateway. Nothing is connected until you choose regions and press
Connect, or turn on "Connect when the gateway starts".
