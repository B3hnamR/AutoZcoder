# AutoZCoder 2.1.2

A Windows desktop startup reliability and diagnostics patch.

## Desktop startup

- Gateway readiness checks now bypass inherited HTTP proxy settings when connecting to the gateway's own listener. A system proxy can no longer intercept the launcher's local dashboard health probe and cause the launcher to shut down a healthy server after the 30-second timeout.
- The readiness loop records the target URL, probe count, last HTTP/connection error, server state, and worker failure state in the diagnostic log.
- Exceptions escaping the gateway background thread are now logged with full tracebacks. Fatal launcher exceptions are also recorded, including `SystemExit` paths that the previous `except Exception` handler missed.
- The same direct-connection helper is used for existing-instance checks and local generator shutdown requests.

## Diagnostics

The desktop log remains at `%LOCALAPPDATA%\ZcodeGateway\zcode-gateway.log`. Startup failures now include the underlying exception instead of only showing a generic message.

## Upgrading

Replace the old executable with the 2.1.2 release. Existing configuration and account data are preserved.
