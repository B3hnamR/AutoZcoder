# AutoZCoder 2.1.5

Maintenance release based on the 2.1.4 feature set.

## Included

- Full English / Persian (FA) dashboard localization and RTL support.
- Persian in-app Guide and bundled offline Vazirmatn font.
- Fixes for JavaScript syntax defects and missing localization keys.
- Corrected release-test assertions so the automated release checks validate the localized UI.
- Windows executable metadata and application version aligned at **2.1.5.0**.

## Validation

This release candidate is based on the 2.1.4 release branch after the CI test fixes. The GitHub Release workflow will run the full Windows and Linux test suites, build both binaries, verify checksums, and publish the release only after all checks pass.

## Upgrade

Replace the existing executable with the 2.1.5 build. No configuration migration is expected.
