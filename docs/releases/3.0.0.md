# AutoZCoder 3.0.0

The generator now treats the bundled exit networks as first-class routing, in
manual signup and in Auto Generate alike: pick VPN sources, rotate through
them at random, and see each attempt on its own page. Alongside that are retry,
update and deploy fixes.

## Routing

- **Multiple IP sources.** Tick any combination of proxy pool, My network,
  pinned proxy, Psiphon and Surfshark. Choosing a bundled network keeps the
  signup inside the networks you ticked.
- **Random or pinned.** "Random" draws a provider first, then a region, and
  never reuses the exit just used. "Stay on one" pins a VPN exit and falls back
  to another connected exit when the pinned one drops. The mode row appears only
  while a VPN is selected.
- **Live exit list.** The exit picker follows connect and disconnect events,
  restores a saved pin when it comes back, and is disabled while nothing is
  connected. Start is refused with the reason instead of quietly using the
  local address.
- Sources are validated and round-trip through the options file; the last
  source cannot be unticked by mistake.

## Auto Generate

- The same IP source, mode and exit settings as manual signup, stored with the
  Auto profile. Manual selections no longer leak into an automatic run.
- **Concurrent browsers** is yours to set, 1–100 slots, with the cooldown slots
  sized and restored to match.
- **Captcha solver**: `auto` (CV + AI vote), `ai` (AI judge only), `classic`
  (CV solver) or `mint` (headless token). Each mode has its own prerequisite
  check; the AI readiness gate now applies only to AI modes.
- **Attempt workers** moved to the Auto Generate page: live log tails, Open log,
  Copy log, Copy password, Kill, Remove and Clear finished. The manual board
  lists manual workers only.
- Plan badges match manual signup (Starter, Start Plan, 500M, global build,
  No plan). "No plan" now appears only when an account was actually created and
  checked.
- **Start Plan qualification** accepts a live Start Plan whose quota bucket has
  not landed yet, while still rejecting a drained bucket or an expired plan. A
  new account that already found the plan active skips the redundant campaign
  claim instead of logging "nothing claimable" over it.
- A final signup call that gets no response is reported as
  `finish_signup_failed` and written to `recovery_accounts.txt`. Losing the
  selected exit pauses the queue as `proxy_unavailable` rather than burning the
  failure budget.

## Manual signup

- Workers gained Open log, Copy log and Copy password.
- Claim-all moved off the pool page (still in the generator).
- Sidebar split into Generator and IP Routes; start renamed to "Start manual
  signup" and moved into its card.
- Generator start is blocked until a mail domain is routed and its inbox
  verified, with a link to Email setup.
- Every Settings option is type- and range-checked before it reaches
  `config.yaml`, with a round-trip test over all editable keys.

## Gateway

- An upstream stream error that arrives before any content is retried
  transparently; the real upstream status is preserved for errors that cannot
  be retried.
- Surfshark "New address" picks a server no other location uses and refuses
  when none is left.
- The Linux updater and its rollback probe the health endpoint on the configured
  host, scheme and port instead of a hardcoded `8788` over HTTP.
- Worker processes cap their BLAS/OpenMP thread pools at one thread. Several
  parallel browsers otherwise exhaust the commit charge and the child dies
  during import with `OpenBLAS: Memory allocation still failed after 10
  retries`. An operator-set thread count is kept.
- The 3-second generator status no longer carries the whole VPN server
  inventory; only `/vpn/status` does.
- Cloudflare deploys run wrangler on a pinned Node 22. Current Node majors
  (25/26) crash wrangler at startup, which previously surfaced as nothing but
  `Node.js vNN`. Failures now show the real error line, and `ZAI_WRANGLER`
  overrides the pinned pair.

## Notes

- `ip_sources` accepts comma- or space-separated lists.
- Nothing changes for existing installs until you touch the routing controls;
  old single-source profiles keep working.

## Upgrading

Replace the executable (Windows) or run the installer (Linux). Saved options,
accounts, VPN keys and Auto profiles are kept.
